# Security policy

## Reporting a vulnerability

Email **api@demexchange.com**. Please do not open a public issue or pull request
for a security report.

Include enough to reproduce the problem: affected package and version, the
request or code that triggers it, and what you observed. We will acknowledge
receipt and tell you what we intend to do about it.

Please give us a reasonable opportunity to ship a fix before disclosing publicly.
